# Referências avaliadas em 23/10/2026

- https://github.com/carlacazv/agentic-holistic-testing — README e licença MIT (copyright Carla Cury, 2026) consultados. Aproveitados conceitualmente planejamento por risco, revisão independente, rastreabilidade, evidências com checksum e separação entre atividade concluída e resultado aprovado. Nenhum código ou pacote desse projeto foi incorporado. O runtime Node e suas dependências não são necessários a esta versão Python.
- https://playwright.dev/docs/test-agents — planner, generator e healer avaliados para evolução futura. Planejamento, geração e reparo devem permanecer separados; nenhum reparo pode transformar falha real em aprovação sem nova execução observada. Não instalado como motor do produto.
- https://code.visualstudio.com/docs/agent-customization/agent-skills — skills em pastas próprias com SKILL.md e frontmatter; adotado o formato portátil para nove procedimentos locais.

Princípios de testes: definição separada de execução, cobertura de critérios, risco, evidência objetiva, defeitos e conclusão humana. A organização é inspirada em práticas de ISTQB e ISO/IEC/IEEE 29119, sem alegação de certificação ou conformidade normativa integral. Não foi copiado texto de normas.
